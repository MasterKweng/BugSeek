# 🔴 前端研发交付标准（完整版）

**核心原则**：用户体验优先、防御性编程、极致性能、数据安全。

### 1. 交互体验与防抖（交互红线）
*   **【强制】防止重复提交**：所有涉及写操作（提交、支付、删除）的按钮，点击后必须立即切换为 `Loading` 或 `Disabled` 状态，直到后端响应返回。严禁让用户有机会连续点击。
*   **【强制】高频事件节流**：搜索联想、窗口 Resize、滚动监听等高频触发事件，必须使用 `Debounce`（防抖，建议 300ms）或 `Throttle`（节流）处理。
*   **【强制】拒绝白屏**：
    *   首屏加载必须展示 Skeleton（骨架屏）。
    *   异步请求耗时超过 500ms 必须展示 Loading Spinner。
    *   严禁页面在数据加载过程中出现“空白”或“假死”。
*   **【强制】友好异常提示**：配置全局拦截器，严禁向用户展示 `undefined`、`Network Error` 或后端原始堆栈信息。
    *   401：静默跳转登录。
    *   500：提示“服务开小差了”。
    *   超时：提示“网络连接不稳定”。

### 2. 渲染性能与资源优化（性能红线）
*   **【强制】长列表虚拟滚动**：DOM 节点超过 100 个的列表（如评论区、表格），必须使用 Virtual Scroll 技术，仅渲染可视区域节点。
*   **【指标】首屏性能**：FCP (First Contentful Paint) < 1.5s，LCP (Largest Contentful Paint) < 2.5s（WIFI环境下）。
*   **【强制】资源加载策略**：
    *   路由组件必须按需加载（Code Splitting）。
    *   非首屏大图必须懒加载（Lazy Load）。
    *   大于 50KB 的静态资源必须上 CDN 并压缩。
    *   单页面 JS Bundle 体积（Gzip后）不得超过 500KB，超标必须拆包。

### 3. 代码质量与安全（代码红线）
*   **【强制】空值防御（NPE防御）**：访问嵌套对象属性必须使用可选链 `?.` 或设置默认值 `|| {}`。严禁因后端返回 `null` 导致 JS 报错白屏。
*   **【强制】XSS 防御**：严禁直接使用 `v-html` (Vue) 或 `dangerouslySetInnerHTML` (React) 渲染用户输入的内容，必须经过清洗（Sanitize）。
*   **【强制】规范化提交**：Git Commit Message 必须符合 Angular 规范（`feat:`, `fix:`, `style:`），否则拒绝合并。
*   **【强制】Lint 零容忍**：项目必须配置 ESLint + Prettier，CI 流水线中 Lint 报错直接打回，禁止构建。

### 4. 监控与兜底
*   **【强制】请求超时设置**：所有 Axios 请求必须配置 Timeout（建议普通接口 10s，文件类 30s）。
*   **【建议】前端监控**：接入 Sentry 或类似监控平台，自动上报 JS Error、资源加载失败和白屏异常，附带用户操作栈。
