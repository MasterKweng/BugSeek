## 2）`extract_field_specs()` 改造

当前这个方法只是把 `ApiSchemaExtractor.extract_definition_fields()` 的结果 `asdict()` 后返回 。

### 最终版问题

这样返回的 field spec 缺少后续最终版真正要用的上下文：

* `risk_level`
* `domain_anchor`
* `allowed_tables`
* `field_position`
* `summary/description digest`

### 最终版做法

在这个阶段先把“纯提取”升级成“提取 + 轻量上下文补齐”。

### 建议改法

```python id="1jge3b"
def extract_field_specs(...):
    definitions = self._get_definitions(project_id, definition_ids)
    items = []
    for definition in definitions:
        field_specs = self.api_extractor.extract_definition_fields(...)
        for field_spec in field_specs:
            item = asdict(field_spec)

            item["field_position"] = item.get("source_type")
            item["risk_level"] = self.risk_policy.classify_field_risk(item)
            item["domain_anchor"] = self._resolve_domain_anchor(definition, item)
            item["allowed_tables"] = self._resolve_allowed_tables(
                project_id=project_id,
                version_id=version_id,
                definition=definition,
                field_item=item,
            )
            item["summary"] = getattr(definition, "summary", None)
            item["definition_description"] = getattr(definition, "description", None)

            items.append(item)
    return items
```

* `_resolve_domain_anchor()`
* `_resolve_allowed_tables()`

* `FeatureBuilder`

## 4）`rank_recall_items()` 改造

当前做法是：

1. 复制 `candidate_evidence`
2. 调 `deterministic_rules.apply_from_dict()`
3. 调 `ranker.rank_from_dict()` 

### 最终版缺口

现在没有先跑 `FeatureBuilder`，也没有在 rank 后补 runtime verification。

### 最终版改造顺序

改成：

1. `FeatureBuilder`
2. `DeterministicRules`
3. `CandidateRanker`
4. `RuntimeVerificationService`

### 推荐实现

```python id="roj6g2"
def rank_recall_items(self, recall_items):
    ranked_items = []
    for item in recall_items:
        candidate_evidence = [dict(candidate) for candidate in item.get("candidate_evidence", [])]

        # 1. 先补上下文特征
        for candidate in candidate_evidence:
            self.feature_builder.enrich_candidate(field_item=item, candidate=candidate)

        # 2. 再跑规则层
        for candidate in candidate_evidence:
            self.deterministic_rules.apply_from_dict(item, candidate)

        # 3. 排序
        ranked_candidates = self.ranker.rank_from_dict(candidate_evidence)

        # 4. runtime verification 对 topK 做二次验证增强
        verified_evidence = self.runtime_verification_service.build_runtime_field_evidence(
            definition_id=int(item["definition_id"]),
            api_field_path=str(item["api_field_path"]),
            candidates=ranked_candidates[:10],
        )
        ranked_candidates = self._apply_runtime_verification_evidence(
            ranked_candidates,
            verified_evidence,
        )

        ranked_items.append({**item, "rule_candidates": ranked_candidates[:10]})
    return ranked_items
```

### 新增 helper

* `_apply_runtime_verification_evidence()`

### 作用

让 runtime verification 真正影响排序和后续决策，而不是只放着。

## 5）`optimize_ranked_items()` 改造

当前逻辑没错，大方向可以保留：

* 高分 rule 先出结果
* 低置信再触发 AI
* AI 候选如果弱于 rule，就 fallback 

### 最终版只需要补 2 个点

#### A. AI 触发条件改成“低置信 + 高歧义”

不要只看一个 threshold，还要看：

* `top1-top2 margin`
* `risk_level`
* 是否已有 lineage 强证据

#### B. AI 返回后重新过一次特征和规则门禁

尤其高风险字段，不允许 AI 直接压过强 lineage 证据。

### 推荐做法

新增一个 helper：

```python id="gziorr"
def _should_trigger_ai(self, item, rule_candidates, ai_confidence_threshold):
    if not rule_candidates:
        return True
    top1 = rule_candidates[0].get("score", 0.0)
    top2 = rule_candidates[1].get("score", 0.0) if len(rule_candidates) > 1 else 0.0
    margin = top1 - top2
    risk_level = item.get("risk_level", "medium")

    if any(
        float(rule_candidates[0].get("features", {}).get(feature, 0.0)) >= 0.9
        for feature in ("f_sql_lineage_exact", "f_code_assignment_hit", "f_runtime_field_hit")
    ):
        return False

    if risk_level == "high":
        return top1 < 0.95 or margin < 0.12

    return top1 < ai_confidence_threshold or margin < 0.08
```

### 目标

AI 继续做补全，但不越权。

### 推荐实现

```python id="hh1l6x"
def _build_decision_artifact(self, item, final_candidates):
    candidate_list = [self._normalize_decision_candidate(candidate) for candidate in final_candidates[:10]]
    top_candidate = candidate_list[0] if candidate_list else None

    relation_type = self.relation_classifier.classify(
        field_item=item,
        top_candidate=top_candidate,
    )

    if top_candidate is not None:
        top_candidate["relation_type"] = relation_type

    calibration = self.confidence_calibrator.calibrate(
        field_item=item,
        ranked_candidates=candidate_list,
        decision_source=str(item.get("decision_source") or "rule"),
        rule_top_score=float(item.get("rule_top_score", 0.0) or 0.0),
    )

    confidence = calibration.get("confidence")
    confidence_bucket = calibration.get("confidence_bucket")
    review_policy = calibration.get("review_policy")

    # 高风险最终门禁
    if top_candidate and not self.risk_policy.should_allow_auto_accept(item, top_candidate):
        review_policy = "manual_review"

    artifact = DecisionArtifact(
        definition_id=int(item["definition_id"]),
        definition_method=str(item["definition_method"]),
        definition_path=str(item["definition_path"]),
        api_field_path=str(item["api_field_path"]),
        field_name=str(item["field_name"]),
        top_candidate=DecisionCandidate(**top_candidate) if top_candidate else None,
        candidate_list=[DecisionCandidate(**candidate) for candidate in candidate_list],
        relation_type=relation_type,
        confidence=confidence,
        decision_source=str(item.get("decision_source") or "rule"),
        decision_trace={},
        project_id=item.get("project_id"),
    )

    artifact_dict = asdict(artifact)
    artifact_dict["confidence_bucket"] = confidence_bucket
    artifact_dict["review_policy"] = review_policy
    artifact_dict["risk_level"] = item.get("risk_level", "medium")
    artifact_dict["decision_trace"] = self._build_decision_trace(item, artifact_dict)

    return artifact_dict
```

### 要新增 helper

* `_build_decision_trace()`
