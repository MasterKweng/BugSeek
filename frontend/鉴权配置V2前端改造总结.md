# 鉴权配置 V2.0 前端改造总结

## 改造完成内容

### 1. 类型定义 (`frontend/src/types/auth.ts`)

创建了完整的 TypeScript 类型定义：

- **InjectionConfig**: 注入逻辑配置
  - `key`: Header Key
  - `value_template`: Value 模板（支持 `{token}` 变量）
  - `add_to`: 添加位置（header/query/cookie）

- **AcquisitionConfig**: 动态获取配置
  - `url`: 登录接口 URL
  - `method`: 请求方法
  - `headers`: 请求头
  - `data`: 请求体/参数
  - `extract_rule`: Token 提取规则

- **AuthConfigV2**: V2.0 鉴权配置
  - `config_version`: 版本标识（v1/v2）
  - `source_mode`: 来源模式（static/dynamic）
  - `injection`: 注入逻辑配置
  - `acquisition`: 动态获取配置

- **枚举定义**:
  - `SOURCE_MODE`: static/dynamic
  - `ADD_TO`: header/query/cookie
  - `EXTRACT_TYPE`: jsonpath/regex/header

- **默认配置**:
  - `DEFAULT_INJECTION_CONFIG`: 默认注入配置
  - `DEFAULT_ACQUISITION_CONFIG`: 默认获取配置

### 2. 自动获取配置抽屉组件 (`frontend/src/components/AuthAcquisitionDrawer.tsx`)

实现了右侧抽屉组件，包含：

**功能模块**:
1. **登录接口配置**

4. **调试测试**

   - 测试结果展示（成功/失败状态）

**符合前端代码规范**:

- ✅ 友好异常提示（message.error）

## UI 交互流程

### V2.0 配置流程

1. **启用鉴权**
   - 打开"启用鉴权"开关

2. **配置注入规则**
   - 输入 Header Key（如 `Authorization`）
   - 输入 Value 模板（如 `Bearer {token}` 或 `Token {token}`）
   - 选择添加位置（Header/Query/Cookie）

3. **选择来源模式**
   - **静态模式**：直接粘贴 Token
   - **动态模式**：点击"⚙️ 配置自动获取逻辑"

4. **配置自动获取（动态模式）**
   - 输入登录接口 URL
   - 选择请求方法
   - 配置请求 Headers 和 Body
   - 设置 Token 提取规则
   - 点击"⚡ 立即运行并校验"测试
   - 保存配置

5. **保存鉴权配置**
   - 点击"保存"按钮
   - 系统自动保存为 V2.0 格式
