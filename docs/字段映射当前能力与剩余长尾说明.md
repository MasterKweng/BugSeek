# 字段映射当前能力与剩余长尾说明

## 当前能力

当前字段映射主链已经具备以下能力，并且都已经接入实际决策链，而不是停留在独立 helper 或 parser：

- 强证据召回：
  - SQL lineage
  - code lineage
  - runtime verification
- 裁决链：
  - FeatureBuilder
  - DeterministicRules
  - CandidateRanker
  - RelationClassifier
  - ConfidenceCalibrator
- 高风险门禁：
  - RiskPolicy
  - 最终决策高风险 gate
  - AI guardrail
- 运行时交叉校验：
  - response_value_match
  - sql_projection_verified
  - code_assignment_verified

## 已覆盖的复杂场景

### SQL lineage

- 多表 join
- CTE
- 多层 CTE transform 透传
- 聚合表达式：
  - count
  - sum
  - max
  - min
  - avg
- 条件表达式：
  - case when
- 函数包裹：
  - date_format
  - 通用函数调用

### ORM lineage

- resultMap
- association
- collection
- columnPrefix
- select -> resultMap 表名继承
- JPA 注解：
  - @Table(name=...)
  - @Column(name=...)

### Code lineage

- setter assignment
- property assignment
- MapStruct target/source 注解
- 链式 getter/setter
- 中间变量传播
- builder 风格赋值
- BeanUtils.copyProperties 的同名字段展开

### Runtime verification

- response payload 取值校验
- db value 对比
- SQL projection 与候选精确收窄
- code lineage 与值匹配联合派生 code_assignment_verified

## 已补的真实样例回归

当前已经有 3 组更接近项目现场的 fixture 回归：

- 订单详情链路
  - 多层 CTE
  - mapper association
  - assembler setter / 中间变量 / builder / BeanUtils
  - JPA @Column
- 报表链路
  - 聚合字段
  - 日期格式化字段
  - mapper + assembler
- 用户资料链路
  - JPA 注解
  - BeanUtils.copyProperties
  - 显式字段覆盖

对应测试文件：

- `backend/tests/test_field_mapping_real_sample_regression.py`

## 当前仍未完全覆盖的长尾

以下能力还没有完全做透，仍然是后续增强空间：

- 更复杂 SQL：
  - union / union all
  - correlated subquery
  - window function
  - 更复杂函数嵌套
- 更复杂 ORM：
  - 注解式 mapper 方法与 SQL 关联恢复
  - JPA relation 注解推断
  - MyBatis discriminator
- 更复杂 code：
  - Bean copy ignore/include rule
  - 自定义 converter / formatter
  - lambda / stream / collection transform
  - 工具类包装后的多跳字段流转
- 更复杂 runtime：
  - 集合字段逐项校验
  - 枚举映射表参与值级验证
  - 多条候选共用同一 projection alias 的歧义收敛

## 建议的下一步

如果继续提升上限，建议顺序如下：

1. 补更复杂 SQL 长尾：
   - union
   - window function
   - correlated subquery
2. 补 code converter / Bean copy rule：
   - ignoreProperties
   - converter method
3. 补真实仓库样例回归：
   - 从现有项目里提取 5 到 10 条典型 API 链路
4. 把线上人工修改反馈反灌到样例集，做持续回归
