## 二、当前仍是骨架、尚未填实的部分

### 1. SQL lineage 仍是轻量版

当前已具备基础 parser 和 recaller，但还没有深入支持：

- 复杂 join 路径展开
- 子查询展开
- 动态 SQL
- MyBatis XML 复杂映射
- 多方言细节
- 表达式级精确 source column 提取

### 2. Code lineage 仍是轻量版

当前已经能承接简单赋值链和结构化 payload，但还没有深入支持：

- MapStruct 全量解析
- BeanUtils / copyProperties 混合链路
- 中间 DTO/VO/Assembler 多段跳转
- 条件赋值与循环赋值链

### 3. Confidence / relation / rules 仍是第一版策略

当前已经形成独立模块，但还没有做到：

- 真正的数据驱动校准
- 更细的 relation taxonomy 覆盖
- 规则优先级冲突治理
- 规则回归基线

### 4. history / lexical / vector 已增强，但还不是最终版

当前仍未完成：

- history 的 domain/path pattern 真实差异化建模
- lexical 的更复杂 family/sibling 协同
- vector 的更细粒度表约束与召回策略控制

### 5. runtime verification 仍是骨架版

当前最需要补实的是：

- 从真实 response 提取 leaf value
- 从真实执行结果提取可比较 DB 值
- 建立稳定的 `response_value_match`
- 建立真实 `sql_projection_verified`
- 建立离线 verification evidence 生产链路
